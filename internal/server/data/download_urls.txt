# Download list: large synthetic test files published by hosting providers and
# CDNs for bandwidth testing. They contain filler bytes, not software, and the
# agent streams them to a discard sink; nothing is ever written to disk or run.
# Every URL here returned HTTP 200 with a binary content type and the expected
# Content-Length via cmd/urlcheck on 2026-09-05. Sizes are 10 MB to 100 MB.
# Plain http:// entries are kept on purpose so tests carry some unencrypted
# traffic too. Re-check with:
#   go run ./cmd/urlcheck -file internal/server/data/download_urls.txt -max-bytes 2000000 -all
